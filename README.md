# Expense-Tracker
💰 Expense Tracker

A simple Expense Tracker web application built using HTML, CSS and JavaScript.

This project helps users manage their daily expenses easily. Users can add, edit, delete, filter and sort their expenses.

Features

* Add new expenses
* View all expenses
* Edit existing expenses
* Delete expenses
* Filter expenses by category
* Sort expenses by amount and date
* Calculate total expenses
* Calculate monthly expenses
* Dark Mode and Light Mode
* Save data using LocalStorage
* Responsive design for mobile and desktop

Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* LocalStorage

Project Structure

Expense-Tracker/
│
├── README.md
├── index.html
├── script.js
└── style.css

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Start adding your expenses.

Storage

The application uses Browser LocalStorage to save expense data.

Your expenses remain saved even after refreshing the page.
